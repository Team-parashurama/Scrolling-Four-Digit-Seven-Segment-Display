🔢 Scrolling Four-Digit Seven-Segment Display

«A simple FPGA-based digital display project built using Verilog HDL.»

---

✨ What is this?

A small digital design project where we make a four-digit seven-segment display scroll through a sequence of numbers.

The display continuously moves through:

2210  →  3211  →  0322  →  1032  →  2103  →  🔄

Behind this simple output, we worked with clock division, counters, multiplexing, and seven-segment decoding.

---

⚡ How It Works

       FPGA CLOCK
           ↓
    ⏱️ CLOCK DIVIDER
           ↓
   🔄 SCROLLING LOGIC
           ↓
   🔢 DIGIT SELECTION
           ↓
   💡 7-SEGMENT DECODER
           ↓
     🖥️ DISPLAY OUTPUT

The four digits are switched rapidly using multiplexing, making them appear continuously visible.
